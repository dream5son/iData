# US-004 查看数据源元数据

## 用户故事

作为 **实施工程师**，我想要 **在管理界面按数据源浏览并核验已抽取的表、列与索引等元数据**，以便 **确认数据字典与源库结构一致，为后续治理与智能体检索打下可核对的资产视图**。

## 优先级 / 依赖

| 项 | 说明 |
| :--- | :--- |
| 优先级 | P0 |
| 依赖 | US-003 连接后自动抽取并持久化元数据 |
| 被依赖 | 无（US-006 提供历史版本浏览时，本故事的默认视图为「当前字典」；历史切换在 US-006） |

## 需求说明

PRD 要求反射结果进入数据字典；实施工程师必须能在 IDI 中只读查看这些结果。本故事不提供语义编辑（表说明/列说明/外键人工锁定属于后续语义补全故事）。

### 1. 入口与导航

- 从数据源列表或详情进入「元数据」视图，绑定单一数据源。
- 导航层次：数据源 → Schema → 表 → 列 / 索引与物理结构。
- 无 Schema 概念的方言（或仅有默认 schema）时，界面仍可浏览，不强制实施工程师选择空的 Schema 节点。

### 2. 数据源级摘要

元数据页顶部展示：

- 数据源名称、类型、连接状态
- 最近一次抽取任务状态（`进行中` / `成功` / `部分成功` / `失败` / 尚未抽取）
- 最近抽取完成时间（无则为空）
- 表数量等汇总（以当前字典为准）

抽取进行中时，允许查看 **已落库** 的上一版字典，但必须明确标注「抽取进行中，以下为抽取开始前的数据」或等价文案，不得把过期数据标成未加说明的「当前」。

### 3. 表列表与表详情

表列表展示：Schema 名、表名、表类型、创建时间、存储大小、原厂注释（过长可截断，详情中全文）。

进入表详情后：

- **列**：列名、数据类型、数据精度、是否可空、是否主键、默认值
- **索引与物理结构**：索引名、单列/复合及列顺序、索引类型、是否唯一、分区/分桶键；无则空状态而非报错

### 4. 搜索与过滤

- 支持按表名关键字过滤表列表。
- 支持按列名关键字过滤当前表的列，或在数据源范围内搜索列名并定位到所属表。
- 无匹配时展示空状态。

### 5. 空态与异常态

| 情形 | 界面要求 |
| :--- | :--- |
| 从未抽取或字典为空 | 空状态，说明需等待自动抽取或在就绪后重试抽取 |
| 抽取失败且无历史字典 | 展示失败原因入口（任务摘要），不假装有表 |
| 部分成功 | 展示已成功对象，并用提示列出失败对象可在任务详情查看 |
| 数据源已停用 | 仍可只读查看已有字典，并提示数据源已停用、内容可能过期 |

本故事的查看为只读：不可在此页修改类型、注释、主键等源库结构字段，也不可编辑业务语义字段。

## 验收标准（Given / When / Then）

### AC-001 浏览到列与索引

- **Given** US-003 已成功抽取至少一张含列与索引（或明确无索引）的表
- **When** 实施工程师打开该数据源元数据，选中该表
- **Then** 能看到列的类型、可空、主键、默认值；能看到索引/分区信息或「无索引/无分区」空态

### AC-002 Schema 分层

- **Given** 源库存在多个 Schema 且均已被抽取
- **When** 实施工程师在元数据树或分组中切换 Schema
- **Then** 表列表仅显示该 Schema 下的表

### AC-003 按表名搜索

- **Given** 字典中存在名称可区分的多张表
- **When** 输入表名关键字
- **Then** 列表只保留名称匹配的表；无匹配时为空状态，不是错误页

### AC-004 按列名搜索

- **Given** 某列名只出现在部分表中
- **When** 实施工程师按列名搜索
- **Then** 能定位到包含该列的表并查看该列属性

### AC-005 尚未抽取的空状态

- **Given** 数据源已就绪但抽取未完成且字典为空
- **When** 打开元数据页
- **Then** 展示空状态与抽取任务状态，不展示伪造表结构

### AC-006 抽取中不误标当前

- **Given** 字典中已有上一轮数据，新一轮抽取 `进行中`
- **When** 实施工程师查看元数据
- **Then** 可看到已有数据，且界面标明正在抽取、内容可能不是最新，不得无标记地称为已是最新当前库结构

### AC-007 抽取失败提示

- **Given** 最近抽取 `失败` 或 `部分成功`
- **When** 打开元数据页
- **Then** 有明确状态提示；部分成功时已成功表可浏览；失败对象可通过任务信息查看

### AC-008 只读

- **Given** 实施工程师处于元数据查看页
- **When** 尝试修改列类型、注释或删除表节点（UI 与 API）
- **Then** 无编辑提交入口，或提交被拒绝；字典内容不变

### AC-009 原厂注释展示

- **Given** 源库表或列带有原厂注释并已抽取
- **When** 查看对应表/列详情
- **Then** 注释原文可见（表列表可截断，详情完整）

### AC-010 停用后仍可查看

- **Given** 数据源已停用但字典仍在
- **When** 打开元数据
- **Then** 只读内容可浏览，并提示数据源已停用

## 非功能与约束

- 元数据查看面向实施工程师，须在常规字典规模下交互可接受（表列表分页或虚拟滚动，避免一次渲染数万行卡死）。
- 展示字段与 US-003 持久化字段对齐，不在本故事引入业务别名或 LLM 描述。
- 实现落点：IDI 前端元数据浏览页 + 后端字典查询接口。

## 范围外

- 编辑表说明、列说明、外键关系或「锁定」语义（语义补全故事）。
- 定时同步、漂移列表的专门治理流（US-005 定义漂移查看；本故事可链到抽取状态，不实现漂移 diff UI 的完整需求）。
- 按版本切换历史快照（US-006）。
- 终端用户或 Agent 侧的 Schema 剪枝检索 UI。
- 抽样数据预览、行级数据浏览（本故事只看结构元数据，不看表内业务行）。
