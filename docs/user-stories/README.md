# 用户故事索引

本目录存放 iData 产品用户故事。故事依据 [PRD](../prd.md) 拆分，每个文件包含角色与价值、需求说明、验收标准、非功能约束与范围外说明。

当前批次覆盖 **实施工程师视角**：从接入异构数据源到查看元数据（含定时增量同步与快照另起故事）。不包含语义补全、RBAC/RLS/CLM 与 Playbook。

## 依赖关系

```text
US-001 接入数据源
   └── US-002 深度连接测试
          └── US-003 自动抽取元数据
                 ├── US-004 查看元数据
                 └── US-005 定时增量同步
                        └── US-006 元数据快照版本
```
