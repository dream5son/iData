# US-002 深度连接测试

## 用户故事

作为 **实施工程师**，我想要 **对已保存的数据源执行深度连接测试**，以便 **在接入生产前确认网络可达、凭证合法、只读事务可用且方言兼容，避免带病连接进入后续抽取与查询链路**。

## 优先级 / 依赖

| 项 | 说明 |
| :--- | :--- |
| 优先级 | P0 |
| 依赖 | US-001 接入并管理异构数据源 |
| 被依赖 | US-003 连接后自动抽取并持久化元数据 |

## 需求说明

数据连接模块在实施工程师配置连接信息后，必须能触发深度连接测试。测试按固定顺序执行四步，任一步失败则数据源不得进入「已就绪」，并返回分步结果与原因。

### 1. 触发方式

- **保存前测试**：在新建/编辑表单中，使用当前表单值（含尚未保存的修改）发起测试，不强制先落库。
- **保存后测试**：对已存在的数据源手动点击「测试连接」。
- 状态为 `已停用` 的数据源允许测试以排查配置，但测试通过也不得自动改为 `已就绪`（须先启用再测通）。

### 2. 分步校验顺序与含义

系统须 **依次** 执行以下四步，前一步失败则后续步骤标记为「未执行」，不得跳过失败步骤宣称整体成功。

| 顺序 | 校验项 | 通过条件 | 失败时对实施工程师的说明原则 |
| :--- | :--- | :--- | :--- |
| 1 | 网络可达性 | 在超时时间内能够与目标主机/endpoint 建立网络连接 | 指出不可达或超时，不暴露内网拓扑细节以外的凭证 |
| 2 | 凭证合法性 | 使用配置的认证信息成功完成数据库登录/鉴权 | 仅提示认证失败或权限不足，不回显或记录明文凭证 |
| 3 | 只读事务支持 | 能够开启只读事务（或等价的只读会话约束，如 `SET TRANSACTION READ ONLY` / 连接参数只读），且探测性写操作被拒绝或不可用 | 明确说明目标连接不支持只读事务或账号具备不可接受的写能力 |
| 4 | 方言兼容性 | 系统能识别并使用该数据源类型对应的 SQL 方言，完成一次无害的只读探测（如读取版本或空结果集查询） | 类型不受支持、方言未适配或探测语句不被目标库接受时失败 |

只读探测不得修改源库数据、不得创建/删除对象。

### 3. 结果、状态与记录

- 测试结果必须分步展示：每步 `通过` / `失败` / `未执行`，失败步带原因摘要。
- **四步全部通过**：
  - 已保存且未停用的数据源状态更新为 `已就绪`；
  - 保存前测试通过 **不单独** 把未保存草稿写成 `已就绪`；实施工程师随后保存成功后，若测试基于与保存配置一致的参数，保存后状态可为 `已就绪`，否则仍为 `草稿` 并提示需用已保存配置再测。
- **任一步失败**：已保存数据源状态为 `测试失败`（停用者保持 `已停用`），不得进入 `已就绪`。
- 记录最近一次测试时间、总体结果、分步结果；供列表展示「最近测试时间」。
- 日志与审计中可记录测试动作与失败分类，禁止写入明文密码、证书私钥、Token。

### 4. 与只读声明的关系

US-001 中「只读连接」声明默认开启。本故事的第 3 步为强制校验：即使实施工程师关闭只读声明，系统仍须执行只读事务探测，并在失败时阻止 `已就绪`。关闭只读声明不得作为跳过第 3 步的手段。

## 验收标准（Given / When / Then）

### AC-001 四步全部通过

- **Given** 数据源已按 US-001 保存，目标库网络可达、凭证正确、支持只读事务、方言已适配
- **When** 实施工程师触发测试连接
- **Then** 四步均为通过，数据源状态变为 `已就绪`，记录最近测试时间；测试在秒级完成（见非功能）

### AC-002 网络不可达

- **Given** 主机、端口或 endpoint 不可达或连接超时
- **When** 触发测试
- **Then** 步骤 1 失败，步骤 2–4 为未执行，状态不得为 `已就绪`，原因说明为网络不可达或超时，不含凭证明文

### AC-003 凭证错误

- **Given** 网络可达但用户名、密码或密钥错误
- **When** 触发测试
- **Then** 步骤 1 通过，步骤 2 失败，后续未执行；提示为认证失败；响应与日志无明文凭证

### AC-004 不支持只读事务

- **Given** 鉴权成功，但无法开启只读事务，或只读探测表明连接可执行写操作且无法收口为只读会话
- **When** 触发测试
- **Then** 步骤 3 失败，状态不得为 `已就绪`，原因明确指向只读事务/只读能力不满足

### AC-005 方言不兼容

- **Given** 前三步可通过，但类型无适配方言或只读探测语句不被目标库接受
- **When** 触发测试
- **Then** 步骤 4 失败，状态不得为 `已就绪`，提示方言不兼容或类型未适配

### AC-006 停用数据源测通不升为就绪

- **Given** 数据源状态为 `已停用`
- **When** 测试四步全部通过
- **Then** 分步结果为通过，状态仍为 `已停用`，不自动变为 `已就绪`

### AC-007 保存前使用表单值测试

- **Given** 实施工程师在编辑表单中修改了主机但尚未保存
- **When** 点击测试连接
- **Then** 使用当前表单值（含未保存修改）执行四步测试；不覆盖库中已保存配置，除非实施工程师随后保存

### AC-008 失败后可重试

- **Given** 最近一次测试失败，状态为 `测试失败`
- **When** 实施工程师修正配置并再次测试且四步通过
- **Then** 状态更新为 `已就绪`，分步结果与最近测试时间更新为本次

### AC-009 测试过程不写源库

- **Given** 任意数据源测试
- **When** 测试执行完毕（成功或失败）
- **Then** 源库中无因测试产生的表、数据行或 schema 变更

### AC-010 并发测试可区分

- **Given** 实施工程师对同一数据源连续触发测试
- **When** 后一次测试开始
- **Then** 界面展示当前进行中的一次测试；完成后以最后一次完成的结果为准更新状态与最近测试时间

## 非功能与约束

- **秒级连接校验**：单次深度测试在目标库正常响应的前提下，P95 完成时间应在秒级（目标 < 5 秒；网络超时须可配置且有上限，避免长时间挂起 UI）。
- 测试使用的探测语句必须只读、无副作用。
- 失败信息面向实施工程师可读，同时避免泄露可被滥用的内部栈或凭证。
- 技术实现落点：IDI 后端连接测试服务 + SQLAlchemy 异步连接；前端展示分步结果。

## 范围外

- 元数据反射与持久化（US-003）；测试通过后自动抽取由 US-003 定义，本故事只负责连通性与就绪状态。
- 定时探活、连接池生产查询、Agent 执行 SQL。
- CVE 多语句注入防护、AST 拦截等运行时安全屏障（内核安全后续故事）。
- 自动修复源库只读权限（实施工程师需在源库侧调整账号）。
