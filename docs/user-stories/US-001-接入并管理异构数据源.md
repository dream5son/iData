# US-001 接入并管理异构数据源

## 用户故事

作为 **实施工程师**，我想要 **配置、保存并管理企业异构数据库的连接信息**，以便 **为数据智能体建立稳定、安全、可维护的数据连接体系**。

## 优先级 / 依赖

| 项 | 说明 |
| :--- | :--- |
| 优先级 | P0 |
| 依赖 | 无 |
| 被依赖 | US-002 深度连接测试 |

## 需求说明

实施工程师在 IDI 管理界面完成数据源的全生命周期管理。系统必须兼容企业主流异构数据库，连接层按方言适配，新增数据库类型不改动核心连接模型。

### 1. 数据源生命周期

实施工程师可以对数据源执行以下操作：

- **新建**：填写连接配置并保存，生成唯一数据源 ID。
- **编辑**：修改显示名称、连接参数、SSL 与高级参数；未改动的凭证不得被覆盖。
- **停用**：停用后该数据源不可用于连接测试以外的下游抽取/同步；配置与已抽取元数据保留。
- **启用**：将停用的数据源恢复为可用，需重新通过连接测试后才能进入「已就绪」。
- **删除**：删除前必须二次确认。若该数据源已存在抽取元数据，系统先阻断删除并提示「请先确认级联删除元数据」，实施工程师确认后级联删除连接配置及其元数据字典、同步任务配置；未确认则取消。

### 2. 列表与状态

数据源列表至少展示：

| 字段 | 说明 |
| :--- | :--- |
| 显示名称 | 实施工程师自定义，同租户内不可重名 |
| 数据库类型 | 方言/产品类型 |
| 状态 | `草稿`（已保存未测通）、`测试失败`、`已就绪`、`已停用` |
| 最近测试时间 | 最近一次深度连接测试完成时间；从未测试则为空 |
| 更新时间 | 配置最近一次保存时间 |

支持按名称搜索、按类型与状态筛选。

### 3. 连接配置字段

保存数据源时，实施工程师必须能配置：

| 配置项 | 要求 |
| :--- | :--- |
| 显示名称 | 必填，1–128 字符 |
| 数据库类型 | 必填，选自支持列表 |
| 主机地址 | 必填（云数仓可用对应 endpoint / project 字段替代，见各类型适配） |
| 端口 | 必填（有默认端口的类型可预填，允许修改） |
| 数据库名 / 项目 / Catalog | 按类型必填 |
| 认证凭证 | 用户名+密码，或类型要求的密钥/Token/服务账号；必填 |
| SSL 加密 | 可开关；开启后可上传或粘贴证书、选择校验模式 |
| 高级连接参数 | 可选键值对（超时、schema 搜索路径、warehouse 等），按类型给出常见项提示 |

云原生数仓与部分 OLAP 的连接形态与传统主机+端口不同（例如 BigQuery 的 project/dataset、Snowflake 的 account/warehouse、Databricks 的 host/http_path）。系统须为每种类型提供对应表单字段，但统一落为同一套连接配置模型（类型 + 参数字典），避免每种库一套独立实体。

### 4. 支持的数据库类型

系统须兼容以下类型（连接层按方言适配）：

**传统关系型数据库**

- Oracle
- Microsoft SQL Server
- PostgreSQL
- MySQL
- IBM DB2

**云原生数据仓库与湖仓**

- Snowflake
- Google BigQuery
- Amazon Redshift
- Databricks Lakehouse

**分布式 OLAP 与实时分析引擎**

- ClickHouse
- Apache Doris
- StarRocks
- TiDB
- Greenplum

未在列表中的类型不得在新建表单中可选。新增类型通过适配器扩展，不修改核心数据源模型。

### 5. 凭证与只读意图

- 凭证必须加密存储；任何管理界面、列表、编辑回填、日志、API 响应均不得回显明文密码、密钥或 Token。
- 编辑表单对已保存凭证显示掩码占位（如「已保存，留空则不修改」）；仅当实施工程师输入新值时才更新密文。
- 配置侧须提供「只读连接」声明（默认开启）。保存时记录该声明，供 US-002 校验只读事务能力。Agent 数据库账号在库端剥离写权限的物理收口由后续安全故事落实；本故事要求配置意图明确，且不得引导实施工程师配置可写账号为推荐选项。

## 验收标准（Given / When / Then）

### AC-001 新建并出现在列表

- **Given** 实施工程师已进入数据源管理页
- **When** 选择一种支持的数据库类型，填写合法的显示名称与连接配置并保存
- **Then** 系统生成数据源 ID，列表中出现该数据源，状态为 `草稿`，显示所选类型

### AC-002 必填与格式校验

- **Given** 实施工程师正在新建或编辑数据源
- **When** 提交时显示名称为空、端口非数字、或当前类型的必填连接字段缺失
- **Then** 保存被拒绝，对应字段展示错误提示，已填合法字段保留，不创建或覆盖记录

### AC-003 同名冲突

- **Given** 当前已存在名为「生产数仓」的数据源
- **When** 再新建或将另一数据源改名为「生产数仓」
- **Then** 保存被拒绝，提示显示名称冲突

### AC-004 编辑时凭证不覆盖

- **Given** 数据源已保存加密凭证
- **When** 实施工程师只修改主机或端口并保存，凭证输入框保持空白
- **Then** 原凭证密文不变，其他改动生效

### AC-005 凭证不回显

- **Given** 任意已保存的数据源
- **When** 打开编辑页、查看详情、拉取列表或接口响应
- **Then** 密码、密钥、Token 不以明文出现；仅显示掩码或「已配置」

### AC-006 停用与启用

- **Given** 状态为 `已就绪` 的数据源
- **When** 实施工程师执行停用
- **Then** 状态变为 `已停用`，配置仍可查看；再次启用不直接变为 `已就绪`，须重新测试（见 US-002）

### AC-007 删除确认与元数据级联

- **Given** 数据源已保存
- **When** 实施工程师点击删除
- **Then** 系统要求二次确认；若已有元数据，须额外确认级联删除；确认后连接配置与关联元数据一并删除，列表不再展示；取消则无变更

### AC-008 类型覆盖

- **Given** 新建数据源表单
- **When** 打开数据库类型下拉
- **Then** 可见本故事列出的全部类型，且每种类型能保存对应必填字段（传统库为主机/端口/库名，云数仓为该类型必需的 endpoint/项目等字段）

### AC-009 只读声明默认开启

- **Given** 实施工程师新建数据源
- **When** 未改动只读相关选项并保存
- **Then** 该数据源的只读连接声明为开启

### AC-010 列表筛选

- **Given** 存在多种类型、多种状态的数据源
- **When** 按名称关键字搜索或按类型、状态筛选
- **Then** 列表只返回匹配项；无匹配时展示空状态而非报错

## 非功能与约束

- 连接配置中的密钥类字段仅存密文，密钥轮转与密钥管理系统对接可在实现时选用项目统一方案，但不得明文落盘。
- 同一实施工程师会话内，保存数据源的接口应在常规负载下于 2 秒内返回（不含连接测试，测试见 US-002）。
- 数据源归属后续多租户模型时按租户隔离；当前若无租户，按系统级隔离，名称在可见范围内唯一。
- 技术实现落点：IDI 前端数据源管理页、IDI 后端连接管理接口；方言适配器可后续按类型迭代，但模型与类型枚举须一次覆盖 PRD 列表。

## 范围外

- 深度连接测试的分步校验与「已就绪」判定（US-002）。
- 元数据抽取、查看、定时同步与快照（US-003～US-006）。
- 语义补全、表/列/行权限、Playbook。
- 在目标数据库上自动创建只读账号（由实施工程师在源库侧准备账号）。
- Agent 运行时使用该连接执行 SQL（属内核与安全层后续故事）。
